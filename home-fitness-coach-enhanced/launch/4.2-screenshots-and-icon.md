# 4.2 Screenshot and icon brief

Play Store phone screenshots: portrait, 1080 x 1920 or taller (9:16 up to 9:19.5), PNG or JPEG, 2 to 8 images.
Put the caption in a band at the top of each image (about the top 18%), white text on the app's dark background,
one line, and keep the phone screen below it uncropped. Captions 1 to 5 are the same ones as in the listing copy.

## Capturing with demo mode

1. In `.env`, add `VITE_DEMO_MODE=1`.
2. `npm run build`, `npx cap sync android`, run on a phone or an emulator set to 1080 x 2400.
3. The app opens straight on the home screen as "Aarav" with a 12-day streak. No sign-in, and nothing is sent to Firebase.
4. Capture the 8 screens above (`adb exec-out screencap -p > shot1.png`, or the emulator's camera button).
5. **Remove `VITE_DEMO_MODE=1` from `.env` and build again before making the store build.** `npm run demo:check` fails if the line is still there.

On the dev server you can use `http://localhost:3000/?demo=1` instead (and `?demo=0` to leave).

What demo mode is: made-up names and numbers in `src/lib/demo.ts`. Every server call is answered from that
file; a call with no sample answer is refused. The sample history is only written to a phone that has no
workout history, so do not turn it on over your own data.

Not checked here: I could not run the app, so the demo screens have not been looked at. Expect to adjust
sample numbers after the first capture.

## Icon directions

The adaptive icon is 108 x 108 dp with a 66 dp safe circle in the middle; Play also needs a 512 x 512 PNG.
Keep it to one shape and two colours so it reads at 48 px.

**A. Pulse mark.** A single heartbeat line that rises into a sharp peak (an "A" for Apex), lime (#c8ff3d, the
app's accent) on near-black (#04050a). No text. Says "fitness, energy" at a glance and matches the app's dark
look. Risk: pulse lines are common in health apps, so the peak has to be distinctive.

**B. Streak flame in a ring.** A simple flame inside a three-quarter progress ring, lime to green gradient on
near-black. Says "daily habit" and matches the streak and progress rings inside the app. Risk: flames are
Duolingo's territory; keep the ring dominant so it reads as progress, not fire.

Avoid: dumbbells (generic), a human figure (unreadable small), the app name in the icon, and anything that
looks like a medical cross.

For both, test at 48 px on a light and a dark wallpaper before choosing.
